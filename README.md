# 스마트팜 대시보드

2025년 1~12월 스마트팜 데이터 10,000행을 내장한 단일 HTML 대시보드입니다.

- 지역 다중선택, 작목, 운영상태, 센터명 부분검색, 최소 재배면적, 기준월 범위 필터
- 건수, 수확량 합계, 평균 에너지사용, 최빈 작목 요약
- 필터 결과 전체 CSV 내보내기(UTF-8 BOM)

## GitHub Pages 설정

Settings → Pages → Build and deployment에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 Save를 누릅니다.

배포 후 주소: https://joongkyoonlee.github.io/test/

로컬에서는 index.html을 브라우저로 열어 사용할 수 있습니다.
